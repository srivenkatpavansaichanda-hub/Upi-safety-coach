UPI SAFETY COACH — FUTURISTIC EDITION

Features
- Modern futuristic interface with subtle grid, glow accents and responsive layouts.
- Optional futuristic dark mode with saved preference.
- Search/filter the built-in scam situations instantly.
- Daily safety reminder carousel and one-click copyable safety checklist.
- Website Help Assistant floating at bottom-right. Click the round chat icon to open it.
- Five language choices: English, Telugu, Tamil, Kannada and Malayalam.
- Built-in checks for 15 common UPI scam patterns.
- Safety tips, official cybercrime reporting links and downloadable awareness poster.
- Privacy warnings: never enter real PINs, OTPs, passwords, CVVs, card or bank account details.

Run locally
1. Install Node.js 18 or newer.
2. Open this folder in a terminal.
3. Run: npm install
4. Run: npm start
5. Open http://localhost:3000

AI checker setup (optional)
- Copy .env.example to .env and add your OpenAI API key to the server-side environment only.
- Never put API keys in browser JavaScript or publish .env. API usage may cost money.
- The floating Website Help Assistant answers common website questions using built-in responses and does not claim to be ChatGPT.

Safety and limitations
- This is an educational awareness prototype, not a bank or government service.
- It cannot verify payments, inspect transactions, or submit complaints.
- If you suspect financial cyber fraud in India, contact your bank/payment app promptly, call 1930 and visit https://cybercrime.gov.in/.
- Ask a teacher or trusted adult to review the project before public deployment.
